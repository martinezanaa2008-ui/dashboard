MiDashboard

*Descripción*

MiDashboard es un dashboard sobre la administración para la gestión de ventas.Este nos Permite visualizar información de ventas, clientes, pedidos y productos de  organizada.

*Tecnologías utilizadas*

* HTML5
* CSS3
* JavaScript

*Componentes del dashboard*

* Barra lateral de navegación.
* lugar de resumen.
* Gráfico de ventas mensuales.
* Distribución de ventas.
* Tabla de las últimas ventas.
* Sección de los productos más vendidos.
* Modo claro y oscuro.

*Diseño*

En este se utilizó CSS Grid para poder  organizar de manera adecuada la estructura principal del dashboard y Flexbox para tener una mejor distribución de los elementos internos.Por otra parte, También se utilizaron varias variables CSS para poder  facilitar el manejo de colores y estilos.

*Responsividad*

El dashboard se puede adapta a diferentes tamaños de pantalla mediante Media Queries,con esto permitiendo su visualización en computadores, tablets, etc.

*Accesibilidad*

En este se  utilizaron etiquetas semánticas, atributos ARIA, textos alternativos en imágenes y elementos decorativos que fueron marcados como `aria-hidden` para poder  mejorar la accesibilidad.

las capturas de pantalla del dashboard en diferentes dispositivos se encuentran en la carpeta llamada evidencias.
